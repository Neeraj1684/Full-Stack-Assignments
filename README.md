# Full Stack Development: JSP Assignments

This repository contains a collection of **10 Full Stack Development assignments** built using **Java Server Pages (JSP)**. It serves as a centralized monorepo to organize, track, and demonstrate practical implementations of server-side Java web technologies.

---

## 🚀 Tech Stack

- **Frontend:** HTML5, CSS3
- **Backend:** Java, JSP (Java Server Pages)
- **Database:** MySQL, JDBC (Java Database Connectivity)
- **Server:** Apache Tomcat

---

## 📁 Repository Structure

Each assignment is organized into its own directory, containing the respective source code and `WEB-INF` configurations.

## ⚙️ How to Run Locally

### Prerequisites

Make sure you have the following installed:

1. Java Development Kit (JDK 8 or higher)
2. Apache Tomcat Server (v9 or higher recommended)
3. MySQL Server (or XAMPP/MySQL Workbench)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/Full-Stack-JSP-Assignments.git
   ```

2. **Navigate to the project**

   ```bash
   cd Full-Stack-JSP-Assignments
   ```

3. **Deploy an assignment**

   Copy the desired assignment folder (for example, `Assignment_01`) into your Tomcat `webapps` directory.

4. **Start Apache Tomcat**

5. **Open your browser** and visit:

   ```
   http://localhost:8080/Assignment_01/index.jsp
   ```

---

## 📌 Notes

- Assignments **5–10** require a running MySQL database.
- Update the JDBC connection details (`URL`, `username`, and `password`) according to your local MySQL configuration.
- Ensure the **MySQL Connector/J** (`mysql-connector.jar`) is available in the `WEB-INF/lib` directory.
